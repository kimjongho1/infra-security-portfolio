# 인프라·보안 포트폴리오

인프라·보안 기술지원 및 클라우드 엔지니어를 목표로 학습하고 실습한 내용을 기록하는 포트폴리오입니다. 리눅스와 네트워크 기초, 홈랩 설계·운영, 장애 분석, AWS 클라우드 실습, 운영 자동화를 중심으로 문제 해결 과정과 결과를 정리합니다.

## 2027년 상반기 자격증 로드맵

| 기간 | 자격증 | 학습 목표 |
| --- | --- | --- |
| 1~2월 | 리눅스마스터 2급 | 리눅스 명령어와 시스템 관리, 사용자·권한 및 서비스 운영 기초 학습 |
| 3~4월 | 네트워크관리사 2급 | 네트워크 구조와 프로토콜, 장비 설정 및 문제 해결 역량 강화 |
| 5~6월 | AWS Certified Solutions Architect – Associate (AWS SAA) | AWS 핵심 서비스와 보안·가용성·비용을 고려한 아키텍처 설계 학습 |

※ 실제 시험 일정에 따라 학습 및 응시 시기는 조정합니다.

## 저장소 구성

| 폴더 | 설명 |
| --- | --- |
| `01-Linux-Network-Basics` | 리눅스 운영 및 네트워크 기초 개념, 명령어와 실습 기록 |
| `02-HomeLab-Architecture` | 홈랩 구성도, 가상화 환경, 시스템 설계 및 구축 문서 |
| `03-Troubleshooting-Reports` | 장애 상황, 원인 분석, 조치 과정과 재발 방지 내용을 담은 기술지원 보고서 |
| `04-AWS-Cloud-Lab` | AWS 서비스 실습, 클라우드 아키텍처와 운영·보안 설정 기록 |
| `05-Automation-Scripts` | 반복적인 운영·점검 작업을 줄이는 자동화 스크립트 |
